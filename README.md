# IIPCT website rebuild

Static build of the new website for Tsi Kanonhkhwatsheríyo Indigenous Interprofessional Primary Care Team (iipct.org).

Built by [Pixel Elite Media](https://pixelelite.ca).

## Run it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

There is no JavaScript. The pages are plain HTML generated by the Python scripts in `tools/generator/`.

## How it's put together

- One HTML file per page. Shared styles are in `assets/css/site.css`, images in `assets/img/`.
- Layout and colour are inline on the elements, because the pages were exported from the design canvas. `site.css` holds the base rules, hover states, the dropdown menus and the narrow-screen rules. Those rules use `!important` to override the inline styles.
- Breakpoints (max-width): 1399 small laptops (header keeps one booking button), 1199 the nav becomes a menu button and links and buttons grow to at least 40 px tall for touch, 1099 tablets (hero stacks, sections tighten), 940 text set below 12 px is lifted to 12 px (the logo lockup keeps its size), 900, 760 phones, 480 small phones.
- Desktop dropdowns are CSS only. The phone and tablet menu, the contact page questions and the staff extension lists are `<details>` elements, so they open without script.
- Fonts come from Google Fonts: Newsreader (headings), DM Sans (text), Kaushan Script (footer words).

## Where the facts live

Every phone number, fax, email, address, hour, map link and staff extension printed on the site comes from
`tools/generator/facts.py`. Each record there names its source on IIPCT's current site (iipct.org). To change one,
edit `facts.py` and regenerate. Never type a clinic fact into a page module.

- One main line, (343) 478-0196, reaches every location; callers press 1 Tyendinaga, 2 Kingston, 3 Bancroft,
  4 Deseronto, 5 Shannonville. The other numbers IIPCT publishes are fax numbers and are shown only as "Fax".
- Online booking is IIPCT's Ocean page (an outside link). This site has no forms and never collects personal or
  health information.

## Regenerate the pages

Needs Python 3 with Pillow.

```
python3 tools/generator/export_site.py .
```

Run it from the repo root. It rewrites the pages, `assets/css/site.css` and the images the pages use, and leaves
files whose content did not change untouched. Never edit a generated `.html` file or `site.css` by hand: change the
Python (`lib.py` for the shared parts, `p_*.py` for each page family, `facts.py` for the facts) and regenerate.
Real photographs go in `tools/generator/site-img/<folder>/` (listed with their source in `site-img/SOURCES.md`) and
are placed with `lib.photo()`. The page list is `PAGES` in `build.py` plus `NAMES` and `DESC` in `export_site.py`.

## Check the pages

```
python3 -I tools/check-site.py . --strict
```

It fails on broken links and anchors, missing images, duplicate ids, missing alt text, missing titles or
descriptions, and in `--strict` also on `href="#"` links, buttons that cannot work without JavaScript, and
`[bracketed]` placeholder text (allowed only on the two draft legal pages). `--online` also tries every outside link.

## Publish the test site

```
tools/publish-preview.sh
```

It copies the pages and `assets/` from the current commit to the `gh-pages` branch, adds a `noindex` tag so search
engines skip the test copy, and pushes. The test site is https://terryjones1995.github.io/iipct/ .
`tools/publish-preview.sh --dry-run <empty-folder>` writes the files without committing.

## Before this goes live

**Legal pages.** Privacy Policy and Accessibility are drafts. Highlighted `[bracketed]` items need IIPCT's details
(privacy officer, analytics, safeguards, accessibility contact, clinic accessibility), and the wording needs their sign-off.
That includes the plain-text promises IIPCT has not made anywhere yet: the WCAG 2.0 Level AA goal, service animals,
support persons and assistive devices, notices of service disruptions, and "We don't sell personal information".
The "Services we use" list names BambooHR because the Careers page is getting its job links; drop that row if it does not.

**Facts to confirm with IIPCT.** Tyendinaga opens at 7:30 am on Fridays (as the current contact page says; every other
day opens at 8:30). The Deseronto waitlist flyer says "press 3" but the contact page says Deseronto is option 4 (the
site uses 4). Deseronto's postal code is not printed anywhere by IIPCT, so it is left off. The staff extension lists
are copied from the current contact page and will go out of date as staff change.

**Events.** `events-programs.html` still shows the sample events from the design mock-ups (dated April to June 2025).
None of them are real IIPCT events.

**News.** On `news.html` the "View flyer" links go nowhere yet, and the "From Facebook" block is a placeholder.
The Breast Cancer Screening story still has a placeholder where the list of staff and partners to thank goes.

**TB Testing.** The current page is two images with no text. `tb-testing.html` has a placeholder until that text is
typed out.

**Other pages.** Placeholder links (`href="#"`) and `[bracketed]` placeholders (staff, board and testimonial names and
quotes) remain on Home, Who We Are, Board, Careers, BPSO, Services, Immunization, Events & Programs and News. Other work
packages are correcting them. Run the checker above to see what is left.

**People.** Several pages still use stand-in photos from the design mock-ups. Some show people who are not IIPCT staff
or clients. Replace them with real photographs before launch. The banners on the Contact page's location cards are
stand-in scenery (no people); photos of the real locations would be better (only Deseronto has one so far).

**Logo.** `assets/img/logo-emblem.png` is a cleaned-up copy of a 216 px file. Get the original vector from IIPCT.

**404 page.** `404.html` uses relative links. A missing address at the top level (`.../iipct/old-page.html`) shows it
with its styles. A missing address one folder deep or more (`.../iipct/contact-us/`) shows it without styles, and its
links lead to more missing pages. Every old iipct.org bookmark has that folder shape (`/contact-us/`,
`/who-we-are/career-page/`), so fix this before the domain moves: publish `404.html` with links that start from the
site root (`/iipct/...` on the test site, `/...` on the real domain). The publish step is the place for it, because it
knows the address the site is served from.
